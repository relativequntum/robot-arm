# 开放问题看板（自动生成，禁止手改）

> **本文件由 `.github/workflows/issues-board.yml` 自动生成，禁止手动编辑。**
>
> 当前为占位内容：首条 issue 建立（或在 GitHub 的 Actions 页手动触发一次该 workflow）后，机器人会重建本文件并提交回 `main`，占位内容将被整体覆盖。
>
> 用法：每次开工先 `git pull`，再看本文件「按人待办」里自己名下的条目；issue 全文与评论用 `gh issue view N --comments` 读。
>
> **找不到自己登录名那一节时不要判定为「无待办」**：成员A / B / C 登录名尚为 `<待登记>`，总管还没把他们写进 `.github/workflows/issues-board.yml` 的 `MEMBERS` 数组，回填前这些成员在「按人待办」里不会有章节。此时改用 `gh issue list --assignee @me --state open` 查自己被指派的条目，并浏览下方模块章节找正文或评论里 @ 到自己的条目，同时提醒总管补登记。
