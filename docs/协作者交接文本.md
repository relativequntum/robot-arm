# 协作者交接文本

> 生效日期：2026-09-15。项目：Seeed reBot DevArm B601-RS 机械臂功能开发。仓库：https://github.com/relativequntum/robot-arm （private，单 `main` 分支）。

## 使用方法

每位成员按以下四步接入（**顺序不能换**）：

0. **装 git、Python、Claude Code**：git —— Windows `winget install --id Git.Git -e`（macOS `brew install git`，Ubuntu `sudo apt install git`），下载页 https://git-scm.com/downloads ；Python 3.10+ —— https://www.python.org/downloads/ ；Claude Code —— 按官方安装说明 https://docs.claude.com/en/docs/claude-code/setup 装好并登录。
1. 在自己电脑上新建一个**空文件夹**（建议命名 `robot-arm`），**在该文件夹内**打开 Claude Code（终端 `cd` 进该文件夹再运行 `claude`）。
2. **在这个会话里**粘贴下面「让 Claude 装 gh」那一段，按它的提示由本人完成 `gh auth login`（系统终端执行，或在 Claude Code 输入框以 `!` 前缀运行）。这一步会顺带把 git 的 GitHub 凭据配好——**这正是之后能 clone 这个 private 仓库的原因**，跳过它第 3 步一定失败。
3. 回到**同一个 Claude Code 会话**，找到下面属于自己的那一段文本（通用成员段 + 个人信息表里自己那一行），**整段复制粘贴**发送即可。

> 第 1—3 步在**同一个目录、同一个 Claude Code 会话**里完成。clone 之后还要按提示退出并重启 Claude Code 一次（原因见各段内的说明）。

> 前置条件：完成上面第 1 步即满足（能 clone / push 本仓库）。仓库是 private，还需要总管邀请你、并且你已在邮箱或 GitHub 通知里**接受邀请**，否则 clone 会 404。模型选择：日常用 Opus，复杂架构、疑难联调、关键校验用 `/model` 切到 Fable 5，子代理同理。
>
> 五点补充（全员适用）：
> 1. **gh CLI 标准配置**：安装可以让 Claude 代劳（见下面「让 Claude 装 gh」那一段），但 **`gh auth login` 这一步由本人操作**——它是交互式的（选 GitHub.com / HTTPS / 凭据 / 按 Enter 打开浏览器），在系统终端执行，或在 Claude Code 输入框以 `!` 前缀运行（`! gh auth login --web`）。授权后你的 Claude 才能自动读 issue 全文、代贴评论、关闭 issue。完整步骤见 `CLAUDE.md` 同名小节，本条只是提醒。
> 2. **Git 配置**：首次接入执行 `git config --global pull.rebase true`；推送被拒先 `git pull --rebase` 再推——看板机器人会向 `main` 自动提交，这类被拒属正常现象，不是出事了。
> 3. **跨模块问题走 GitHub Issue**：任何需要别人表态的口径/接口问题，一律开 issue（用模板，打标签 + 指派 + 必要时群里 @），**写在文档里的会签请求不算发出**。每次开工 `git pull` 后先看 `docs/看板.md` 里自己名下的条目。普通事项不群 @，只有「阻塞他人开工 / 有截止硬约束 / 需当日回应」三种才群 @。
> 4. **让 Claude 开 issue 的标准命令**（gh CLI 会绕过网页端的模板强制，所以正文与标签必须自己带全）。**`--template` 只在交互式终端里生效，Claude Code 的 Bash 是非交互 shell，带 `--template` 必报错，且它与 `--body-file` 互斥——所以一律走 `--body-file`**：
>
>    ```
>    # Claude 先读 .github/ISSUE_TEMPLATE/huiqian.md，删掉顶部 --- 之间的 YAML front matter，
>    # 按栏位填好写入临时文件，再执行：
>    gh issue create --title "[会签] 一句话概括问题" --body-file <填好的临时文件> --label 会签 --label 硬件 --assignee <登录名>
>    ```
>
>    裁决用 `caijue.md` + `--label 裁决`，任务用 `renwu.md` + `--label 任务`；本人想用网页模板时才跑 `gh issue create --web`。四要素——正文按模板栏位写全、类型标签、模块标签、`--assignee`——缺一项视为未发出。完整说明见 `CLAUDE.md`「gh CLI —— 全员标准配置」一节，以那里为准。
> 5. **硬件在 Linux 上跑**：机械臂控制经 CAN（socketcan，`can0`，1 Mbps）运行，需要 Ubuntu / Jetson + CAN-USB 转换板。Windows 只做开发与写文档，任何实机调试都要到 Linux 机器上做；没有实机时先用仿真（MuJoCo / RViz）验证，别拿实机试手。

## 让 Claude 装 gh（全员，在第 1 步新建的目录里、打开 Claude Code 之后粘贴）

> 本段是粘贴用的操作稿；安装与授权的规则以 `CLAUDE.md`「gh CLI —— 全员标准配置」一节为准，冲突时以 CLAUDE.md 为准。

```text
请帮我安装 GitHub CLI 并确认可用。

1. 先执行 gh --version 检查是否已安装；已装就跳到第 3 步。
2. 未安装则按我的系统安装：Windows 执行 winget install --id GitHub.cli -e；macOS 执行 brew install gh；Ubuntu 按 https://github.com/cli/cli/blob/trunk/docs/install_linux.md 的官方 apt 源步骤装。装完提醒我新开一个终端（PATH 才会生效）。
3. 登录这一步必须我本人操作，你不要替我跑。告诉我两种做法任选：在系统终端（PowerShell / Windows Terminal，macOS、Linux 用系统终端）执行
   gh auth login --web --hostname github.com --git-protocol https
   或者直接在这个 Claude Code 输入框里输入带 ! 前缀的同一条命令（! gh auth login --web --hostname github.com --git-protocol https）。它会问是否用 GitHub 凭据配置 git（选 Yes），然后打印一次性 code 并等我按 Enter 打开浏览器，把 code 贴进去完成授权。
4. 我说完成后，你执行 gh auth status 给我看结果，并用 gh repo view relativequntum/robot-arm 验证我对本项目仓库有访问权限；如果报 404 或权限错误，说明我还没接受仓库邀请，提醒我去邮箱或 GitHub 通知里接受，不要去试别的地址。
```

## 响应流程模板句（被指派 / 被 @ 后对自己的 Claude 说）

> 我在 issue #N 被指派了会签。先 git pull 看 docs/看板.md 我名下待办，再用 gh 读 #N 全文和评论，结合相关文档给出意见草稿，我确认后你用 gh issue comment 贴出。
