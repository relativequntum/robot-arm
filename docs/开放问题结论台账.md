# 开放问题结论台账

## 用途

`[会签]` 与 `[裁决]` 类 issue 关闭后，由**提出方**（会签）或**总管（唯一属主）**（裁决）在本表回填一句话结论，编号从 Q-01 顺延。目的是让「最终定下来的口径」能一眼查到，不必翻 issue 长评论。

规则：

- 只登记 `[会签]` 与 `[裁决]`；`[任务]` 类**不回填**——任务 issue 是执行记录，不是结论，回填会把台账变成打卡表。
- 结论必须先落在 issue 里（关闭前在 issue 正文/评论写清），本表只是把那句话搬过来并附链接。
- 一句话写「定了什么」，不写过程与理由；细节看 issue 链接。
- 关闭即回填，当日完成；回填是关闭动作的一部分，漏填由总管盘点时补。
- 若结论后来被新的裁决推翻，不要改旧行，新增一行并在结论里写明「取代 Q-0x」。

生效日期：2026-09-15。
