## 一、产品参数

| 项目 | 参数（B601-RS） |
|---|---|
| 自由度 | 6 DOF + 1 夹爪 |
| 负载 | 2.5 kg |
| 最大臂展 | 754 mm |
| 重量 | 约 6.7 kg |
| 重复定位精度 | < 0.2 mm |
| 推荐工作空间 | 臂展的 70% |
| 供电 | DC 48V |
| 总线 | CAN，1 Mbps（`bitrate 1000000`），Linux 走 socketcan，默认通道 `can0` |

同系列对比：B601-DM 为达妙电机版，负载 1.5 kg、臂展 767 mm、重量约 4.5 kg、DC 24V。两版**外观与机械结构相同，仅电机不同**——查 DM 的资料时注意区分，参数不可混用。

### 电机与电气

- **电机**：RobStride（骑士智能）无刷电机，`RS00` × 4（约 $125/个）、`RS06` × 3（约 $210/个），共 7 个关节电机。
- **上位机接口**：CAN-USB 转换板（预刷 PCAN 固件，约 $15），套件内附 PCAN-USB。
- **电源**：官方推荐明纬 `LRS-600-48`（48V / 12.5A，约 $69.5）；wiki 写「48V 12.5A MeanWell Power Supply」，追求满性能可上 48V 25A。**整机出厂不含电源**，也可自接电池。
- **供电接插**：XT30 2+2 电源分线板（约 $15）+ XT30 2+2 线束（两端弯头 320mm ×1、200mm ×4，单端弯头 300mm ×1，直头 ×1，需自行定制）+ XT30U 母转 XT60 公转接线，XT60E 固定母座出线，美标三芯 AC 电源线。
- **控制器**：无专用主控板，由 PC / Jetson 直接经 CAN 驱动电机。官方推荐边缘控制器为 reComputer J3011（Orin Nano 8GB）或 NVIDIA Jetson AGX Thor。
- **配套主臂（Leader Arm）**：Star Arm 102 / Star Arm 102-LD，12V 10A 供电（也可用 SO-ARM101 的 12VDC 适配器），串口 `/dev/ttyUSB0`。

### 机械件与选配

- 机械件：MGN9-170mm 直线导轨 ×1 + MGN9 滑块 ×2（夹爪）、6803ZZ 轴承 ×3、AXK5578 推力轴承 ×1、模数 1 / 16 齿 / 6mm 孔齿轮 ×1、30×9×2mm 硅胶垫 ×1。
- 可选腕部相机支架：32×32 UVC、Intel D435i、Intel D405 & Gemini 305、Gemini 2（STEP 放在 `hardware/reBot_B601_DM/3D_Printed_Parts/` 下，RS/DM 共用）。
- 许可：硬件 CERN-OHL-W-2.0，软件 Apache-2.0（2026-05-11 起由 CC BY-SA-NC 切换为 CERN-OHL-W 2.0，全场景商用合规）。OSHWA 开源硬件认证号 CN000024。
- 销售形态：RS 版有 Full Kit（未组装全套）与 Pre-assembled（整机）；DM 版有五种套件。

```
Rebot_Arm_description/

```

- 使用**相对路径**，复制时必须保持整个模型目录完整，不要把 STL 拍平到单一目录。
- 面向 Web、RViz、ROS 2、MuJoCo 复用；但**不是**当前应用运行时自动读取的唯一目录，RS/DM 项目各自另有运行时资源位置。
- RS 与 DM 夹爪物理结构相同，10 个精细碰撞 STL 文件相同；RS 的这 10 个全部只供 MuJoCo 用，DM 有 4 个同时作为 URDF 外观。
- 因 RS 的 MJCF 局部坐标约定，**RS 的「左」对应 DM 的「右」文件**，命名需注意。

## 三、软件栈

### 1. 底层 SDK —— MotorBridge（本项目主路线）

- `pip install motorbridge`，**Python ≥ 3.10**，当前 v0.5.0。
- 统一 Python API 覆盖 Damiao(4310/4340P/6001)、RobStride(rs-00~rs-06)、MyActuator(X8)、HighTorque(HT)、Hexfellow；传输层 SocketCAN、CAN-FD、DM Serial。
- 核心类 `Controller`：`Controller("can0")`、`Controller.from_socketcanfd("can0")`（Hexfellow CAN-FD）、`add_damiao_motor()`、`enable_all()`、`motor.send_mit()`、`motor.get_state()`。
- 另有 Web UI 与 MotorBridge Studio（Windows / Ubuntu / macOS），用于写电机参数、设零位。

### 2. 运动学层 —— reBotArm_control_py

Python，基于 Pinocchio 运动学动力学库 + MotorBridge 多电机协同 SDK，提供正逆运动学与重力补偿，配 MeshCat 可视化。

### 3. ROS 2 —— reBotArmController_ROS2（可选路线）

支持 Humble 与 Jazzy。主推 Ubuntu 24.04 + ROS2 Jazzy + Python 3.12，参考配置 Ubuntu 22.04 + Humble + Python 3.10。

包：`reBotArmController`（控制节点）、`rebotarm_bringup`、`rebotarm_moveit_config`、`rebotarm_moveit_demos`、`robot_state_publisher`；依赖 PyPI 的 `motorbridge`。

```bash
git clone https://github.com/Seeed-Projects/reBotArmController_ROS2.git rebotarm_ros2
sudo apt install -y python3-colcon-common-extensions python3-pip git
sudo apt install -y ros-${ROS_DISTRO}-{control-msgs,trajectory-msgs,tf-transformations,robot-state-publisher,rviz2,pinocchio}
python3 -m pip install --user --break-system-packages motorbridge
colcon build --symlink-install && source install/setup.bash
```

启动：

```bash
ros2 launch rebotarm_bringup bringup.launch.py model:=rs channel:=can0      # 全系统
ros2 launch rebotarm_bringup bringup.launch.py model:=rs channel:=can0 use_rviz:=true
ros2 launch rebotarm_bringup driver.launch.py model:=rs channel:=can0       # 仅驱动
ros2 launch rebotarm_moveit_config demo.launch.py model:=rs                 # MoveIt 仿真
ros2 launch rebotarm_moveit_config hardware.launch.py model:=rs             # MoveIt 实机
ros2 run rebotarmcontroller GravityCompensation
```

配置在 `rebotarm_hardware.yaml`：默认控制模式 `mit`，夹爪开 5.0 rad / 闭 0.0 rad，关节 2/3 重力补偿增益 1.5。重力补偿服务：`/rebotarm/gravity_compensation/start` 与 `/stop`。MoveIt2 集成含 Pinocchio 逆解、OMPL 轨迹规划、碰撞检测、RViz MotionPlanning 插件，示例 `draw_square`、`pick_place`。

### 4. LeRobot（模仿学习 / 数据采集与训练）

使用 Seeed fork `https://github.com/Seeed-Projects/lerobot.git`（wiki 称其为验证过的稳定版，优于官方仓库）；深度相机功能在 `DepthCameraSupport` 分支。

```bash
conda create -y -n lerobot python=3.10
conda activate lerobot
pip install -e ./lerobot
pip install lerobot-teleoperator-rebot-arm-102
pip install lerobot-robot-seeed-b601
```

Torch：CPU 环境 2.6，Jetson 2.3+，RTX 50 系需 PyTorch 2.7.1 + CUDA 12.8。

机器人类型串 `seeed_b601_rs_follower`，`--robot.port=can0 --robot.can_adapter=socketcan --robot.id=follower1`；主臂类型 `rebot_arm_102_leader`，`--teleop.port=/dev/ttyUSB0 --teleop.id=rebot_arm_102_leader`。

```bash
lerobot-calibrate --robot.type=seeed_b601_rs_follower --robot.port=can0 \
    --robot.id=follower1 --robot.can_adapter=socketcan
lerobot-calibrate --teleop.type=rebot_arm_102_leader --teleop.port=/dev/ttyUSB0 \
    --teleop.id=rebot_arm_102_leader
lerobot-teleoperate --robot.type=seeed_b601_rs_follower --robot.port=can0 \
    --robot.id=follower1 --robot.can_adapter=socketcan \
    --teleop.type=rebot_arm_102_leader --teleop.port=/dev/ttyUSB0 \
    --teleop.id=rebot_arm_102_leader
```

数据采集用 `lerobot-record`，训练 `lerobot-train --policy.type=[policy]`，支持 ACT、SmolVLA、Pi0、Pi0.5、GR00T。

> LeRobot 数据集、录像与模型权重体量大，一律放 `local-data/`，不进 git。

### 5. 仿真与上层 Demo

- **Isaac Sim**：RS 版已完成（DM 版进行中）。仓库 `Seeed-Projects/reBot-Isaacsim`，配套 NVIDIA DLI Sim-to-Real VLA 课程。
- **MuJoCo 在线数字孪生**：浏览器直接运行，可切换标准臂与 AGV 构型、控制关节与 TCP、查看俯视与 D405 腕部相机、跑自动归置与码垛 demo。推荐 Chrome 或 Edge，首次加载模型较慢。
- **具身智能体架构**：接受自然语言指令（如「捡起红色方块」）自动规划并执行抓取，源码 `TheMoonAstronaut/wrc`。
- **视觉抓取 Demo**：基于 YOLO + 深度相机（RS/DM 共用同一篇 wiki）。

## 四、CAN 初始化（Ubuntu，每次上电后执行）

```bash
sudo ip link set can0 down 2>/dev/null
sudo ip link set can0 type can bitrate 1000000
sudo ip link set can0 up
ip -details link show can0
sudo chmod 666 /dev/ttyUSB*    # 主臂串口权限
```

实机操作推荐 Ubuntu 24.04 LTS。Jetson 平台**必须**安装 PCAN 驱动，缺失会导致通信持续失败。

## 六、注意事项（安全与工程）

**安全**

- **安全距离**：运行时与机械臂保持至少 1 米。上电或使能控制器前确认工作区内无人无障碍物。
- **禁止热插拔电机**：插拔电机前必须断开电源。
- **断电 / 断连会失控**：wiki 明确警告掉电或通信中断会导致 runaway 与安全隐患，所有运动场景同等注意。
- **实机前先仿真**：跑任何实机 demo 前先在 RViz 验证规划路径，并随时准备停掉控制器；每条运动指令都要仔细复核，严禁危险操作。
- **环境限制**：禁止在潮湿、高温或多尘环境中使用。

**调试与维护**

- **标定流程**：用 MotorBridge / MotorBridge Studio 写入电机参数并设零位；顺序为「读取当前参数 → 套用默认模板 → 写入电机」，扫描确认关节 1–7 全部在线。
- **主臂标定会清零**：reBot 102 主臂标定说明指出当前位置会被重置为零。
- **Jetson 平台**：必须安装 PCAN 驱动，缺失会导致通信持续失败。
- **串口权限**：主臂需 `sudo chmod 666 /dev/ttyUSB*`。

**装配与机械**

- **装配力矩**：使用电动螺丝刀等动力工具时扭矩设低中档（3–6 kgf·cm），扭矩过大会滑丝造成不可逆损坏。
- **螺丝防松**：套件用标准内六角螺钉，长期运行会松动影响精度，需额外购买热熔胶做螺纹锁固；有电动工具者可改用防松垫圈或带胶螺钉。
- **线束磨损**：线束 1 长期拖拽可能磨损电机接头导致接触不良，建议打印 `RS_Motor1_wiring_harness_clip`（黑色 ABS ×2）缓解。
- **加工精度**：关键尺寸公差 ±0.02 mm（GB/T1840-M），表面处理阳极氧化 / 喷砂，配合件建议 H7 / 过盈配合。
- **BOM 声明**：开源 v1.0 BOM 不代表 Seeed 最终出货版本，为低成本复刻做了简化；量产版会加金属激光打标防呆、部分 3D 打印件改金属件、调整公差、可选编织网线束保护，但**机械结构一致**。
- **URDF 复用**：`Rebot_Arm_description/` 用相对路径，复制时保持目录结构完整；注意 RS 的左右命名与 DM 相反。
